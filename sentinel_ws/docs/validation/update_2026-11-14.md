## 离线检查

临时环境由根.gitignore排除，不提交。可移植测试入口可在安装依赖后复现：

```bash
python -m pip install pytest PyYAML xacro numpy
python sentinel_ws/tools/verify_offline.py
```

结果：**39 passed、3 skipped、1 deselected，4 subtests passed**。
覆盖Xacro实际展开及部件树、惯量、枪管/相机变换、场地资源/碰撞、STL转换、FPS纯逻辑、
Odin服务请求顺序/失败响应和激光/扫描测距参数一致性。
为离线展开Xacro，仅把包资源路径查询映射到源码目录，不伪造ROS消息或节点行为。
工具在中文Windows上自动以UTF-8重启并向测试子进程传递相同编码，避免默认CP936造成读取失败。
移除旧辅助雷达外形后，纠正旧模型测试的13外形断言为12，并验证主雷达盒体与辅助TF无外形。

可移植测试明确排除7个依赖ROS/ament/Linux探针的文件，并取消选择1项ROS launch测试；
3项FPS窗口测试因缺少ROS/PyQt依赖跳过。上述结果不是完整colcon/ROS测试套件通过。
