# 硬件状态

当前雷达型号已按用户设备更新为 **Manifold Odin1 Lite**。本仓库包含Gazebo近似模型、
实体厂家驱动启动封装与地图服务客户端；实体设备联网、运行与安装标定尚未验收。
旧Mid-360名称仅作为原始CAD来源或历史记录保留，不代表当前要接入的设备型号。

## 雷达与软件条件

- 仿真采用一个主雷达：10Hz、240×180、120°×90°、0.15–25m。
- `lidar_link`沿用旧主雷达CAD位置作为仿真占位，`lidar_aux_link`仅保留兼容TF，无外形或扫描。
- 主体外形近似58mm深×69mm宽×69mm高，外壳相对光学中心的显示偏移不是实测标定。
- 实体雷达默认IP为192.168.1.251，PC有线网卡需在同网段。设备数量、序列号、当前IP和固件仍须现场核实。
- 实体入口按官方v3.7.0文档接口编写；v3.x固件需要匹配v3.x驱动，不能忽略固件/驱动对应关系。
- 官方驱动需从厂家取得并编译、source，本仓库不包含其SDK二进制。建图/重定位还需安装 `manifold-lc-sdk` 算法deb。
- 实体原始点云保留厂家 `lidar` 坐标。相机/Body外参应从实际设备获取，机器人安装变换需实测。

官方第12章名义深度为240×180，第5章原始点云写256×192；仿真使用前者，实机应检查
消息width/height/fields。GPU射线没有完整模拟反射率、光照、置信度、RGB、IMU及厂家SLAM。
测距25m和50m具有不同反射率/光照条件，默认仿真采用25m，不能视为所有目标均可测25m。

目标仿真环境为Ubuntu22.04、ROS2 Humble、Gazebo Classic11。实体厂家驱动可按其文档
部署于Humble或Jazzy；这不表示当前Gazebo Classic仿真已经迁移到新版Gazebo。
完整命令、官方资料和限制见 [sentry_perception/README.md](../src/sentry_perception/README.md)。

## 机器人与后续联调

四轮布局和部件名义坐标来自用户CAD，默认使用基础几何与方向摩擦近似。
质量、惯量、摩擦、控制增益仍是仿真假设，不作为实车机械或控制标定。
新增pitch是仿真自由度；实车云台运动和真实传感器TF必须由实际硬件状态支撑。

底盘通信、电机反馈、编码器里程计、机器人定位融合和完整实车启动仍待接入。
当前FPS界面只控制仿真，不提供真实开火或自动瞄准联动。
