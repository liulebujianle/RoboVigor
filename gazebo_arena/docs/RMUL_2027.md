# RMUL 2027 3V3 比赛场地

依据用户提供的《RoboMaster 2027 机甲大师高校联盟赛比赛规则手册 V1.0.0（20261015）》
第 3.2 节、印刷页 21–28、图 3-1 至 3-11 重建。这里“建图”是搭建 Gazebo 三维场景；
不是让机器人跑 SLAM，也不代表新场地定位、巡逻已验收。

## 尺寸与外观

内场 12×8 m；红蓝严格中心对称。以场地内侧西南角为 (0,0)，东为 +X，北为 +Y，
主地面完成面为 Z=0。红方补给区位于西北角，蓝方位于东南角。

主要标称尺寸：高地 2000×4060 mm、高 200 mm；高地控制区 1200×1200 mm；
中央控制区 3000×3000 mm；补给区 2500×2000 mm；工作台 750×450×400 mm；
高地挡边宽 150 mm、长 1800 mm、比高地高 200 mm；隧道净跨 800 mm、净高 250 mm、
顶部 270 mm；金属条宽 350 mm，距高地左侧 825 mm。

地胶厚 2 mm，控制区、补给区和隧道增益区域另加 2 mm 地胶。
交互卡的 92×112 mm、28/70 mm 间距保存在参数文件中；卡片埋在地胶下，
不把说明图的绿色网格、蓝色区域填充或黄色禁区斜线画成实物地面。

纹理 `official_top.png` 直接来自手册 PDF 第 23 页图 3-1 的内嵌图片，
按内场范围裁切，不凭主观选择红、蓝、绿。所有顶部共享同一世界坐标 UV，
保留官方地面标识、地胶纹理和拼缝。原图约 84 像素/米，含烘焙阴影，
其颜色受原渲染照明影响，不能等同于未提供的标准色号或真实材质测量。
大疆素材仅用于用户要求的本地场地复现；版权归原权利人，未自动上传或发布。

参数与证据在 `src/guodong_sentry_sim/maps/rmul_2027/parameters.json`，
分别列出手册标注、计算所得和推定值。手册没有给出完整 CAD、标准 RGB/PBR、
边界高度厚度、全部倒角、结构做法、摩擦等；这些值无法声称“完全相同”。
手册本身也明确未标注部分以实物为准，尺寸通常允许 ±10% 的误差。

## 启动与切回

在 WSL 的本仓库根目录执行（先完成构建）：

```bash
bash scripts/rmul_2027.sh
```

默认使用已有的 preview 机器人外观减轻负载，物理、传感器保持原模型。
如需原 CAD：`bash scripts/rmul_2027.sh visual_quality:=cad`。
原 `sentry_sim.launch.py` 的 `world` 默认值也是 `rmul_2027`。

同一个入口可回切，旧 SDF、PGM、YAML 均保留且部署前后核对 SHA-256：

```bash
bash scripts/rmul_2027.sh world:=depot
bash scripts/rmul_2027.sh world:=sentry_lab
```

配套上位机 `known_map.launch.py`/旧巡逻 demo 仍显式使用经过验收的 Depot 地图。
不要把它的旧坐标直接发到新场地。单独仿真入口用于查看和后续新场地适配。
没有将新场地导航验收状态伪装为旧场地已通过的结果。

## 物理与地图限制

每个场地实体同时具有相同封闭网格的 visual 和 collision，隧道为开放的真实净空，
不是填实的障碍箱。主地面、高地地胶与额外地胶分别保留毫米级高度。

现有机器人是关闭重力的平面速度控制，没有轮地接触或悬架；
添加真实高地不会自动获得上坡/登高能力。原水平激光高约 279.62 mm，
可越过 200 mm 高地及 270 mm 隧道顶；它的扫描平面不等于底盘可通行区域。
不擅自降低传感器、压平场地或更改机器人以隐藏这些限制。

附带 `maps/rmul_2027/rmul_2027.pgm/.yaml`（2.5 cm/格、原点 [-0.4,-0.4,0]）
是面向当前平面底盘的保守障碍投影，封锁高地及隧道屋顶投影；不是实际 SLAM 结果，
也不是已通过 AMCL 验收的激光地图。后续如要自主巡逻，需要先确定地形跟随和导航表示。
本次场景不实现裁判系统 RFID、占点、回血、弹丸或操作间设备功能。

## 重建与检查

```bash
python3 tools/rmul_field.py
python3 tools/test_rmul_field.py
python3 tools/verify_bundle.py
python3 tools/check_rmul_runtime.py  # 需先 source 已安装包；独立域97、随机Gazebo分区
```

生成器仅需 Python/Pillow。现有 CMake 已安装整个 models、maps、worlds、launch 目录，
因此新场地纹理和网格随正常包构建安装，无绝对个人资源 URI、无需 Fuel 在线下载。
`geometry_overlay.png` 中的金色线是审阅辅助线，不会出现在实际场地纹理中。

部署替换前的 launch、manifest、README 和进度文件备份在
`output/validation/rmul_transfer_backups/<时间>/`，原地图文件不移动、不删除。

## 2026-10-16 验证记录

WSL Ubuntu 24.04 / ROS Jazzy / Gazebo Harmonic 构建成功，原有回归与新增检查共 35 项通过。
SDF 在设置包资源路径后通过 `gz sdf -k`。无窗口真实渲染获得俯视、斜视和机器人相机图像，
机器人出生位置 (1.25, 6.75)。点云有效负载 184320 字节；720 束水平激光与本场景实际扫描
高度的解析边界对比，有限返回模式一致率 100%，中位距离误差 1.38 mm，95 分位 21.54 mm。
最大掠射误差 7.884 m 保留，不能声称全部射线精确对齐。
西墙低速碰撞实测最小中心 X=0.299004 m，停车后 X=0.299070 m，
与原碰撞包络半宽 0.299071 m 一致；这不等于全地形碰撞或登高验收。
静态验证与隔离运行明细见 `docs/validation/rmul_2027_source_machine.json`。
